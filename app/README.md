# LaughGG — React 이관

기존 `web/` 정적 페이지를 React + Tailwind 로 옮기는 중이다.
지금 배포는 여전히 `web/` 이 담당한다. 패리티가 날 때까지 둘이 공존한다.

```sh
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # dist/
npm run lint     # tsc --noEmit
```

## 왜 옮기는가

한 페이지가 100KB 넘는 HTML 안에 CSS·스크립트·데이터가 전부 들어 있어서,
색 하나 바꾸려면 여덟 파일을 같은 방식으로 고쳐야 했다. 네비게이션은
파이썬 스크립트로 매번 다시 심었고, 상품 데이터는 페이지마다 복사돼 있었다.
컴포넌트로 쪼개면 고칠 곳이 한 군데가 된다.

## 팔레트

색은 셋 + 흰색이다. op.gg 의 실제 CSS 번들에서 뽑은 토큰만 쓴다.

| 쓰임 | 토큰 |
|---|---|
| 크롬 | darkpurple `900 #1C1C1F` · `850 #282830` · `800 #31313C` |
| 액센트 | purple `400 #A072FF` · `500 #7D59EA` · `600 #6B42DC` |
| 글자 | gray / darkpurple 계열 한 줄 |

네 번째 색인 금색은 배지 엠블럼에만 쓴다 — 배지가 유일하게 색을 갖는다.

기본 테마는 다크다. `index.html` 의 부팅 스크립트가 첫 페인트 전에 정하고,
선택은 `localStorage` 에 남는다. 라이트는 `[data-theme="light"]` 파생이다.

타입 스케일은 12 / 16 / 24 / 32 / 48 px 만 쓴다. 네비만 예외로 10pt · 12pt 다.

## 옮긴 것

| 화면 | 상태 |
|---|---|
| 공통 네비 · 테마 · 장바구니 | 됨 |
| 배지 엠블럼 | 됨 |
| 마켓 목록 | 됨 |
| 상품 상세 | 됨 — 드로어가 아니라 제 주소를 가진 페이지다 |
| 홈 · IR · 게임 스택 · AI · 브이로그 | 아직 `web/` |

상세를 사이드 드로어에서 페이지로 바꾼 게 이번 이관의 실질적인 이유다.
드로어는 화면 폭을 반쯤 덮어 네비를 가렸고, 링크 공유도 뒤로가기도 안 됐다.
나이키도 아마존도 상품 상세는 별도 페이지다.

## 3D

`src/three/baker.ts` 가 WebGL 컨텍스트 하나를 돌려 쓰며 모델을 굽는다.
브라우저당 컨텍스트 수가 제한돼 있어서 카드마다 렌더러를 만들 수 없다.
결과는 data URL 로 캐시하고, 같은 모델·같은 각도는 다시 굽지 않는다.
`Spin` 만 제 렌더러를 갖고, 화면 밖으로 나가면 멈춘다.

에셋은 `public/assets` → `../../web/assets` 심링크다. 이관이 끝나면 옮긴다.
