# LaughGG — React 이관

기존 `web/` 정적 페이지를 React + Tailwind 로 옮기는 중이다.
지금 배포는 여전히 `web/` 이 담당한다. 패리티가 날 때까지 둘이 공존한다.

```sh
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # dist/
npm run lint     # tsc --noEmit
```

## 왜 옮기는가

한 페이지가 100KB 넘는 HTML 안에 CSS·스크립트·데이터가 전부 들어 있어서,
색 하나 바꾸려면 여덟 파일을 같은 방식으로 고쳐야 했다. 네비게이션은
파이썬 스크립트로 매번 다시 심었고, 상품 데이터는 페이지마다 복사돼 있었다.
컴포넌트로 쪼개면 고칠 곳이 한 군데가 된다.

## 팔레트

색은 셋 + 흰색이다. op.gg 의 실제 CSS 번들에서 뽑은 토큰만 쓴다.

| 쓰임 | 토큰 |
|---|---|
| 크롬 | darkpurple `900 #1C1C1F` · `850 #282830` · `800 #31313C` |
| 액센트 | purple `400 #A072FF` · `500 #7D59EA` · `600 #6B42DC` |
| 글자 | gray / darkpurple 계열 한 줄 |

네 번째 색인 금색은 배지 엠블럼에만 쓴다 — 배지가 유일하게 색을 갖는다.

기본 테마는 다크다. `index.html` 의 부팅 스크립트가 첫 페인트 전에 정하고,
선택은 `localStorage` 에 남는다. 라이트는 `[data-theme="light"]` 파생이다.

타입 스케일은 12 / 16 / 24 / 32 / 48 px 만 쓴다. 네비만 예외로 10pt · 12pt 다.

## 공방

이 제품의 논지는 "만드는 능력"이 아니라 **"가진 걸 이 게임에 맞추는 능력"**이다.
생성은 곧 흔해진다. 안 흔해지는 건 컨셉 정합성이다. 그래서 대분류 이름을 기술
이름(AI)에서 하는 일(공방)로 바꿨다. 고객사를 부르는 말이 이미 "게임 스튜디오"라
스튜디오는 쓸 수 없다 — 같은 사이트에서 카피가 꼬인다.

들어오는 문은 셋인데 도착지는 하나다.

```
프리셋 ─┐
프롬프트 ├─→ Knobs { tone warm gloss facet sat line } ─→ 렌더 + 검수 점수
슬라이더 ┘
```

여섯 숫자가 유일한 상태다. 그래서 결과가 재현되고, 남에게 통째로 넘길 수 있다.
`concepts.ts` 의 `knobsFromPrompt` 만 모델 호출로 갈아 끼우면 바깥은 그대로다.

점수는 물리에서 나온다. 광택을 올리면 셰이더가 무거워지고, 각지게 하면 면이 줄어
가벼워지고, 외곽선은 드로우콜을 한 번 더 쓴다. 근거 없는 가산점은 없어서
다크 판타지는 점수가 내려가고 픽셀 레트로는 올라간다.

## 작업물 피드

게시판이 아니다. **빈 글쓰기 칸이 커뮤니티를 죽인다.**

공방에서 작업을 끝내면 그게 곧 게시물이 된다 — 프롬프트와 슬라이더 값과 점수 변화가
붙은 채로. 아무도 "글을 쓰지" 않는데 결과물이 쌓이고 댓글은 거기 달린다.

- **포크가 주 동선이다.** 남의 레시피를 내 에셋에 그대로 돌린다. 구경이 곧 시도가 되고,
  시도가 곧 새 게시물이 된다. 이게 기여 루프의 전부다.
- **실패도 그대로 올린다.** 점수가 떨어진 것만 모아 보는 정렬이 따로 있다. 떨어진 이유가
  붙은 글이 제일 잘 읽히고, 채점 자체에 대한 논쟁을 만든다.
- **점수는 사람이 아니라 물건에 붙는다.** 공개 지표는 포크 수 하나뿐이다. 사람한테
  카르마를 주면 서열과 텃세가 생긴다.
- **익명이 기본이다.** 실명으로는 "이거 프로덕션에 넣었다가 터졌다"가 안 나온다.
  소속만 인증하고 신원은 가린다.
- **씨앗은 운영자가 심는다.** 빈 피드를 열면 아무도 두 번째로 오지 않는다.
  씨앗은 숨기지 않고 표시한다.

상세를 사이드 드로어에서 페이지로 바꾼 게 이번 이관의 실질적인 이유다.
드로어는 화면 폭을 반쯤 덮어 네비를 가렸고, 링크 공유도 뒤로가기도 안 됐다.
나이키도 아마존도 상품 상세는 별도 페이지다.

## 3D

`src/three/baker.ts` 가 WebGL 컨텍스트 하나를 돌려 쓰며 모델을 굽는다.
브라우저당 컨텍스트 수가 제한돼 있어서 카드마다 렌더러를 만들 수 없다.
결과는 data URL 로 캐시하고, 같은 모델·같은 각도는 다시 굽지 않는다.
`Spin` 만 제 렌더러를 갖고, 화면 밖으로 나가면 멈춘다.

에셋은 `public/assets` → `../../web/assets` 심링크다. 이관이 끝나면 옮긴다.
